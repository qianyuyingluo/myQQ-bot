群资料与成员备注

将群名、成员称呼和明确的 @ 对象提供给模型。平台提供的名称会自动记录；手动备注优先，清空备注后恢复使用平台名称。这里只显示已收到或手动添加的成员，不是完整群名单。保存后下一次回复生效。

每次模型请求还会自动附带运行设备上的北京时间（UTC+08:00），包含日期、星期和时分秒。请保持运行设备的系统时间准确。

主动发言

群聊与私聊用户分别设置。普通自动接话遵守等待时间、冷却和次数上限；定时模式独立运行，没人回复也会继续，不受这些上限限制。两种自动模式均遵守下方安静时段，手动发送不受这些规则限制。

私聊请使用用户给机器人发消息时取得的 user_openid，不要直接填写 QQ 号码或拿群成员 ID 代替。

工作文件夹与 Agent

让机器人在指定文件夹中读写代码、运行命令并验证结果。每个群或私聊独立设置，沿用上方模型与 API Key，模型需支持工具调用。Windows 使用真实 PowerShell，以运行机器人的用户权限执行；工作目录是默认位置，不能隔离命令对电脑其他位置的访问。

当前会话 Agent 设置

按钮在运行机器人的电脑上打开文件夹选择窗口。也可手动填写已有路径。选择后需点击保存。

私聊默认填入当前会话用户，保存后才生效。群成员 ID 可在“群资料与成员备注”中查看，或让成员发送 /agent 查看自己的 ID。未列入的成员只能普通聊天；定时发言和自动接话不会执行工具。

任务新建或修改的 PNG/JPG 图片会随结果发送，每个任务最多3张、每张4 MiB，并在下方保留预览。全局一次执行一个任务。QQ 中发送 /agent status 查看结果，/agent stop 停止；停止不撤销已经写入的文件。运行中请先停止任务再修改此会话设置。
